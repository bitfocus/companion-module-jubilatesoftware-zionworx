## ZionWorx

Controls ZionWorx 5 (Jubilate Software) over its local network control API.

**Work in progress.** This module is not finished yet.

### Setting up ZionWorx

1. In ZionWorx, open **Web Remote** and tick **Active**. The window shows the port (normally 7650) and the PC's address.
2. Click **Add API Client…**, name it (for example "Companion") and copy the token. It is shown only once.
3. In Companion, add a ZionWorx connection and enter the PC's address, the port and the token.
